# 대학 경쟁률 대시보드

uway, 진학어플라이의 공개 경쟁률을 검색하고 관심 목록으로 관리하는 간단한 웹앱.

Render에서 진학어플라이가 403을 반환할 때는 [접속 오류 수정 및 배포 안내](RENDER_SETUP.md)를 참고하세요. 수정본 재배포 후에도 IP 차단이 계속되면 실제 접속이 허용되는 국내 연결 경로가 필요합니다.

Node.js 24에서 `npm ci`, `npm start`로 실행합니다. `npm run check`, `npm test`로 검증하고 `npm run diagnose`로 실제 원문 수집을 확인할 수 있습니다.

## 주요 기능

- 대학 및 학과·모집단위 검색
- 모집 인원·지원 인원·경쟁률 확인
- 관심 목록 저장 및 전체 새로고침
- 제공사 원문 갱신 시각 표시

## 주요 파일

- `index.html` — 화면 구조
- `styles.css` — 화면 스타일
- `app.js` — 검색·관심 목록 UI 동작
- `server.mjs` — 공개 경쟁률 원문 파싱

공개 데이터는 각 제공 페이지의 갱신 주기에 따라 달라질 수 있습니다. 최종 결과는 해당 대학의 공식 안내를 확인하세요.
